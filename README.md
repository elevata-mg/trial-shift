# Trial Shift – 30 jours

Jeu web mobile de reconversion : tire un métier à la roue, puis relève 4 semaines de défis (Tri, Dilemme, Timing) pour décrocher ton certificat.

**Jouer :** active GitHub Pages (Settings → Pages → Branch `main` / dossier `/root`), puis ouvre `https://<ton-pseudo>.github.io/<nom-du-depot>/`.

## Contenu
- `index.html` : le jeu complet (un seul fichier, images incluses, aucune dépendance à installer)
- `.nojekyll` : demande à GitHub Pages de servir le fichier tel quel

## Notes
- La progression est enregistrée dans le navigateur (localStorage).
- La police Fredoka est chargée depuis Google Fonts ; hors ligne, une police système prend le relais.
